# تقرير: وصول الأدوات للمزودين وحلقة العمل والإصلاح

## ما أُنجز
- **الأدوات للمزودين العاديين (API):** تمرّ عبر `ToolAgent` (tools أصلية لمزود custom، وإلا بروتوكول `[[TOOL]]`). أُضيف محلل لصيغة DSML (DeepSeek) فتُنفَّذ بدل أن تظهر نصاً خاماً، وتُخفى من عرض المحادثة.
- **الأدوات لمزودات الويب:** عبر `WebToolBridge` (بروتوكول داخل رسالة المستخدم). تعليمات التشخيص أُضيفت لرأس البروتوكول.
- **أسماء معاملات الأدوات:** توحيد `file_path/filename/old_text/new_text/...` إلى `path/old/new/content/command` (سبب «المعامل path مطلوب»). رسالة الخطأ تذكر الآن المفاتيح المرسلة.
- **file_edit:** مطابقة متسامحة مع المسافات وأسطر الالتفاف كمحاولة أخيرة قبل الفشل.
- **بوابة الجودة:** إصلاح إيجابية كاذبة في فاحص توازن الأقواس (regex literals، واقتباسات تمتد عبر الأسطر). هذا كان يدفع النموذج لـ«إصلاح» `web-session.js` السليم في حلقة لا تنتهي.
- **الفشل المتكرر:** عدّاد (أداة + سبب). عند مرتين: تنبيه للنموذج بتغيير الأسلوب. عند 4: توقف برسالة تشرح السبب.
- **منهج التشخيص** في تعليمات وضع المطوّر: فرضية → تحقق مستقل → أصغر تعديل → إعادة الفحص → تغيير الأسلوب عند التكرار → شرح عند التوقف.
- **التقرير النهائي:** صار يتضمن «المتبقي»، «آخر خطأ»، «السبب المرجّح والخطوة التالية».
- **Copilot:** إرسال احتياطي (نقر JS ثم Enter عند بقاء النص في الحقل) ومحددات عربية لزر الإرسال.
- **الواجهة:** إصلاح الهامش المضاعف أسفل صندوق الكتابة وفوق الكيبورد.

## تحديثات الاحترافية والاعتمادية المنفَّذة لاحقاً
- **فحص ذاتي شامل لدورة الأدوات (`ToolSelfTest.kt`):** أُضيفت أداة تشخيص من 4 مراحل آمنة (قراءة فقط 100% عبر `file_tree` مع رمز إثبات وحيد المرة `LION-PROBE-XXXXXX`) متاحة لكل مزود API (في `SettingsParts.kt`) ولكل موقع ويب (في `LionChatSettingsCard.kt`) وفي شاشة أدوات المطور (`DevToolsScreen.kt`)، مع الحفاظ على البروتوكول النصي `[[TOOL]]` دون فرض OpenAI Native Tools على المزودات المجانية.
- **استشفاء تلقائي آمن لجلسة الويب قبل الإرسال (`AndroidWebSessionHost.kt` / `WebPreSubmitRecovery`):** معالجة تلقائية لمرة واحدة فقط قبل إرسال الرسالة (`!submitted && !recovered`) عند توقف عارض WebView أو فشل التحميل الأولي العابر أو انتهاء صلاحية رابط محادثة مستعاد (404/410 مع العودة للمدخل الأساسي وإعادة حقن السياق الكامل وبروتوكول الأدوات)، مع حظر الاستشفاء تماماً بعد الإرسال أو عند أخطاء SSL أو رفض الصلاحية (401/403).
- **فحص مسبق شامل لوسائط الأدوات وتوسيع المرادفات (`AiTools.kt` + `GitHubClient.kt`):** إضافة `AiTools.validateArgs` للتحقق المسبق من جميع المعاملات النصية الإلزامية، والمفاتيح الواجب حضورها حتى لو كانت فارغة (`new` و`content`)، والمعرّفات الرقمية الموجبة (`run_id` و`number` و`job_id` و`artifact_id` و`message_id` و`user_id`)، والمصفوفات الإلزامية، ودعم اسم ملف الـ workflow (مثل `build.yml`) إلى جانب المعرّف الرقمي في `github_dispatch`، مع رسالة خطأ عربية تجمع كل النواقص والتوقيع المتوقع للأداة.
- **تحسينات تحليل وتنظيف DSML و`<tool_call>` وJSON العاري (`ToolCallCodec.kt` + `ToolMarkup.kt` + `WebToolBridge.kt`):** دعم تحويل المصفوفات والكائنات والأرقام والقيم المنطقية في DSML مع حماية الحقول النصية الخام (`RAW_TEXT_KEYS`)، واستخراج عدة استدعاءات JSON عارية متوازنة، وتنظيف كتل `<｜DSML｜function_calls>` و`<tool_call>` من رسائل المحادثة وتطبيعها عند قدومها من صفحات الويب.
- **دقة سقف الخطوات وأسباب التوقف (`ToolAgent.kt`):** احترام تعطيل `autoExtend` عند نهاية الدورة، وإيقاف الدوران العقيم عند انتهاء دورة كاملة دون نجاح أي أداة جديدة، وتصنيف سبب التوقف بدقة (`classifyLoopStop`) بين السقف الأقصى (3 ساعات)، ومهلة الجولة، وسقف الخطوات اليدوي، وتعذّر التقدم، واستنفاد `MAX_CYCLES`.
- **إصلاحات إضافية في `TextEdit.kt` و`ControlPlane.kt` وتغطية اختبارية شاملة:** منع مضاعفة الإزاحة البادئة في المستوى الثالث من `TextEdit.replace`، ودعم تعابير Regex بعد الكلمات المفتاحية (`return`, `typeof`, ...) والـ backticks المهرَّبة في `ControlPlane.balance` (مُتحقَّق منه مباشرة على `web-session.js`)، واجتياز 357 اختبار JUnit و40 اختبار Node JSDOM بنجاح كامل.
