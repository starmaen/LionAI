# توثيق مشروع Accounting Star

## مكونات النظام
- **قاعدة بيانات SQLite** تشمل جداول الحسابات، المخازن، الأصناف، العملاء، الموردين، الفواتير، قيود اليومية، المخزون، الإهلاك.
- **نموذج البيانات** (Kotlin data classes) تمثل الكيانات الأساسية.
- **خدمات الأعمال**: `InventoryService` لإدارة المخزون و`AccountingService` للقيود والتقارير.
- **ملفات بيانات أولية** (`ChartOfAccounts.csv`, `InitialCategories.csv`).

## تقارير متاحة (قابلة للتوسيع)
1. **تقرير المخزون** – إظهار رصيد كل صنف في كل مستودع، مع إمكانية تصفية حسب الفئة أو تاريخ الجرد.
2. **تقرير الأرباح والخسائر** – حساب صافي الربح للفترة المحددة عبر تجميع الإيرادات (قيد مبيعات) والمصروفات (قيد مشتريات، مصاريف تشغيل، إهلاك).
3. **تقرير الميزانية** – إظهار الأصول، الخصوم، وحقوق الملكية في تاريخ معين.
4. **تقرير الجرد** – عرض نتائج الجرد العادي أو النهائي، وتوليد قيود إغلاق الجرد.

## خطوات التطوير القادمة
1. **إنشاء واجهة المستخدم** في مجلد `app/` (Jetpack Compose أو XML).
2. **إكمال منطق الخدمات** بإضافة استعلامات SQLite الفعلية.
3. **إضافة اختبارات** في `tests/` لضمان صحة العمليات.
4. **إعداد طباعة** – توفير ملفات PDF/HTML يمكن إرسالها إلى طابعة عبر Android Print Framework.

## ملاحظات
- جميع الجداول قابلة للتعديل (إضافة/حذف أعمدة) عبر ترقية قاعدة البيانات في `onUpgrade`.
- يمكن إضافة مستودعات فرعية بسهولة عبر حقل `parent_id` في جدول `warehouses`.
- الأصناف تدعم تقسيمًا هرميًا عبر جداول `categories` و`subcategories` (لم تُنشأ بعد، يمكن إضافتها لاحقًا).
