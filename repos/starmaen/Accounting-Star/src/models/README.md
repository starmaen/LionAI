# نماذج الكيانات (Models)

* **Account.kt** – تعريف حسابات دفتر الأستاذ (كود، اسم، نوع، رصيد).
* **Warehouse.kt** – تعريف المخازن (معرف، اسم، موقع).
* **Product.kt** – تعريف الأصناف (كود، اسم، وحدة قياس، سعر شراء، سعر بيع، تصنيف).
* **Customer.kt** – تعريف الزبائن (معرف، اسم، بطاقة تعريفية، عنوان، هاتف).
* **Supplier.kt** – تعريف الموردين (معرف، اسم، بطاقة تعريفية، عنوان، هاتف).
