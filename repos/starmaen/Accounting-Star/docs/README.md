# وثائق مشروع نجم المحاسبة

## نظرة عامة
مشروع نجم المحاسبة هو نظام محاسبي مكتوب بلغة Kotlin. يوفر خدمات لإدارة الحسابات، المخزون، وإعداد التقارير المالية.

## الميزات الرئيسية
- **إدارة الحسابات**: إنشاء وتعديل الحسابات المالية.
- **إدارة المخزون**: تتبع المخزون في المستودعات.
- **التقارير المالية**: تقارير الأرباح والخسائر، الميزانية العمومية، وتقرير المخزون.

## كيفية الاستخدام
1. **إعداد قاعدة البيانات**: تأكد من وجود اتصال بقاعدة البيانات باستخدام `DatabaseHelper`.
2. **استخدام الخدمات**: استخدم الكلاسات مثل `AccountingService`، `InventoryService`، و`ReportService` لإجراء العمليات المطلوبة.
3. **اختبار الكود**: استخدم ملفات الاختبار في مجلد `tests` لضمان صحة الوظائف.

## المساهمة
نرحب بأي مساهمات لتحسين المشروع. يرجى اتباع أفضل الممارسات في كتابة الكود وإضافة الاختبارات المناسبة.
