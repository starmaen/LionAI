# 🦁 Lion AI

مساعد ذكاء اصطناعي عربي لأندرويد، متعدد المزودات، يعمل محلياً على الجهاز.

## الميزات المنفذة فعلياً

- 🤖 **ثلاث مجموعات مزودات، كل في مكانه**: 17 مزود API (مفتاح أو بدون مفتاح)، 22 دردشة ويب مجانية، و18 أداة صور وصوت وفيديو. التفاصيل أدناه.
- 🎛️ **اختيار الموديل بسرعة** من سهم أسفل مربع الكتابة، مع تجاوز اسم الموديل من الإعدادات دون إعادة بناء التطبيق.
- 🎚️ **إعدادات جودة الإجابات**: وضع دقيق يمنع النماذج الضعيفة من الإجابة عن الأسئلة المعرفية، ووضع متوازن وسريع، مع اختيار طول الرد (مختصر/عادي/مفصّل).
- 📚 **RAG محلي للملفات الطويلة (جديد)**: عند تجاوز الملف 18 ألف حرف، يقسّمه التطبيق إلى مقاطع ويختار الأكثر صلة بالسؤال (أو يوزّعها عند طلب التلخيص) بدلاً من إرسال نص قد يتجاوز سياق النموذج.
- 🧩 **إجماع النماذج (اختياري)**: للأسئلة المعرفية، يسأل نموذجين قويين، يقارن إجاباتهما محلياً بنسبة اتفاق، ثم يدمجهما في إجابة واحدة مع نسبة الاتفاق. يُفعّل من الإعدادات ويضاعف الطلبات.
- 🌐 **بحث ويب موثّق (جديد)**: للأسئلة المعرفية والبرمجية، يجمع Lion AI مقتطفات من ويكيبيديا والبحث العام، ومن GitHub وStack Overflow وXDA عند الحاجة، ويحقنها في الطلب مع تعليمات إلزامية، ثم يعرض قائمة المصادر القابلة للنقر أسفل الرد. يعمل مع أي مزود (API أو ويب) لأن السياق يُضاف إلى الطلب، ويمكن إيقافه من الإعدادات.
- 🔐 **تشفير المفاتيح** عبر Android Keystore و`EncryptedSharedPreferences`، مع تعطيل النسخ الاحتياطي.
- 💬 **محادثات متعددة** محفوظة محلياً بصيغة JSON تحافظ على الأسطر الجديدة.
- 🗂️ **علامات تبويب للمحادثات**: تنقّل بين عدة محادثات من الشريط العلوي مع زر ＋، وكل تبويب يحفظ مزوده ومسودته ومرفقاته. علامات التبويب لمزودات API الأساسية فقط، أما صفحات الويب والوسائط فتُفتح في شاشة مستقلة.
- 📎 **مرفقات حقيقية**: ملفات نصية وكود وأرشيف ZIP وصور (حتى 4MB) للمزودات الداعمة للرؤية. دعم PDF وOffice موجود في `Attachments.kt`.
- ⏰ **تذكيرات** عبر AlarmManager وإشعار قابل للنقر.
- 📱 **SMS** وجهات الاتصال: إرسال مباشر عند منح الصلاحية، وإلا يُفتح تطبيق الرسائل للتأكيد.
- 🎤 **إدخال صوتي** (STT) و**قراءة الردود** (TTS) بالعربية.
- 🎨 واجهة محادثة منظمة: مربع كتابة صغير، وأزرار (ملف/صورة/ميكروفون/اختيار الموديل/إرسال) أسفل المربع، وإعدادات قابلة للتمرير مع زر حفظ ثابت فوق لوحة المفاتيح.
- 🗂️ **إدارة المحادثات**: عنوان ذكي يلخّص الموضوع بعد أول رد، تغيير الاسم، أرشفة/إلغاء أرشفة، حذف بتأكيد، وعرض اسم المحادثة في الشريط العلوي.
- 📎 **قراءة كل أنواع الملفات**: PDF (مع تحويل الممسوح ضوئياً إلى صورة)، Word/Excel/PowerPoint (docx/xlsx/pptx)، OpenDocument، ZIP بمحتوى ملفاته، HTML/RTF، وأي نص أو كود بترميز UTF-8 أو Windows-1256، والصور.
- 🖼️ **محرر الصور** (القائمة الجانبية أو زر ✏️ تعديل): تدوير وقلب وقص ومقاسات وسطوع وتباين وألوان وفلاتر وتمويه وحدة وكتابة نص، تراجع، حفظ في المعرض ومشاركة، وتعديل بالكلمات عبر النموذج المختار، وإرسال الصورة المعدّلة للتحليل. اقتراحات سريعة للتحليل (وصف، استخراج نص، ترجمة...).
- 🧠 **العقل المركزي (تلقائي)**: يصنّف كل سؤال محلياً (مجاملة سريعة، عام، معرفي، برمجة، استدلال، كتابة، تحليل صورة، تعديل صورة، ملف طويل) ويختار الأنسب من المزودات المتاحة لديك. الأسئلة القصيرة لم تعد تُرسل تلقائياً إلى النماذج السريعة الضعيفة؛ المجاملات وحدها تستخدم المسار السريع. يستبعد النماذج المعروفة بالهلوسة (مثل gpt-oss-20b وllama-3.1-8b) عند توفر بديل قوي، ويفضّل Gemini/Claude/OpenAI/DeepSeek في الأسئلة المعرفية، ويجرّب بديلاً تلقائياً عند فشل المزود أو رفض الرد المشبوه (جدول غير مطلوب، تكرار، هلوسة، لغة مختلفة). أوضاع «دقيق/متوازن/سريع» و«طول الرد» من الإعدادات، وزر 🔄 إعادة في كل رد لإعادة توليده بأقوى المزودات. عند توفر مصادر ويب، يواصل العقل المركزي تجربة مزودات إضافية بدلاً من رفض الإجابة، ويقبل إجابة مدعومة بالمصادر حتى من مزود أقل قوة مع تنبيه واضح.
- 🆓 **مجموعة API**: مجانية بدون مفتاح (Kilo Gateway وLLM7.io وOVHcloud) ومجانية بمفتاح (Gemini وGroq وOpenRouter وCohere وCloudflare وMistral وTogether وZ AI وNVIDIA NIM وOllama Cloud) ومدفوعة (OpenCode Zen وOpenCode Go وDeepSeek وOpenAI وClaude).
- 🌐 **مجموعة الويب**: Arena وDuckDuckGo وGemini Web وCopilot وGitHub Copilot وClaude Web وDeepSeek Chat وChatGPT وMistral Le Chat وQwen وPerplexity وGrok وHuggingFace وPoe وKimi وMeta AI وZ.ai وPi وYou.com وPhind وGoogle AI Studio وBlackbox.
- 🎨 **مجموعة الوسائط**: صور (Bing Image Creator، Leonardo، Ideogram، Craiyon، Perchance، Playground، Recraft، Firefly، Pollinations) وصوت (ElevenLabs، TTSMaker، Suno، Udio) وفيديو (Luma، Pika، Runway، Kling، Hailuo).
- 🖼️ **محرر الصور الكامل** (منقول من مشروع image-editor ويعمل بدون إنترنت): 8 منزلقات تعديل بمعاينة حية، 10 مرشحات، تحسين ذكي تلقائي (تحليل الإضاءة والتباين والتشبع)، تحويل، قص حر أو بنسب مع إطار، تغيير الحجم، نصوص متعددة الأسطر، فرشاة رسم، مقارنة مع الأصل، وتعديل بالكلمات.
- 🔏 **توقيع ثابت للتحديثات**: كل نسخة توقّع بنفس مفتاح `keystore/lionai-release.jks` ويزداد رقم الإصدار تلقائياً، فتُثبَّت فوق القديمة دون حذفها.
- ⏰ **منبه حقيقي للتذكيرات**: صوت المنبه المتكرر + شاشة كاملة فوق القفل + قراءة صوتية للتذكير + أزرار إيقاف/تأجيل، ورسالة واضحة مثل «حان موعد شرب الدواء الآن» مع التوقيت.
- 🧪 **اختبار المفتاح** في الإعدادات يعرض الخطأ الحقيقي من المزود، وعنوان وسيط اختياري للشبكات المحجوبة (مثل Groq).
- 🔁 **تذكيرات متكررة** («كل يوم الساعة 8 صباحاً») وإشعار واحد واضح لكل تذكير مع زري «بعد 10 دقائق» و«تم»، وقراءة صوتية للتذكير والتطبيق مفتوح، ومشاركة المحادثات كنص.
- 📋 **قوائم موديلات منسدلة لكل مزود** في الإعدادات (قائمة جاهزة + زر «تحديث» يجلب القائمة الحالية من المزود، والمجانية فقط حيث يتيح المزود ذلك) مع إمكانية كتابة أي موديل يدوياً.
- 💳 **OpenCode Zen**: مفتاح Zen من opencode.ai/auth يعمل من هذا التطبيق مع الموديلات المدفوعة عبر `https://opencode.ai/zen/v1`، مع دعم واجهات OpenAI/Anthropic/Google/Responses حسب الموديل. الموديلات المجانية (big-pickle و-free) مخصّصة لتطبيق OpenCode الرسمي وترفض التطبيقات الخارجية بـ `FreeUsageLimitError`.
- 💳 **OpenCode Go / Console**: مزودان منفصلان لنفس المفتاح: «OpenCode Go» لاشتراك Go عبر `zen/go/v1`، و«OpenCode Console» لأرصدة Console الحديثة عبر `inference`.
- 🗣️ **أوامر بلغة طبيعية** (كتابة أو صوت) تعمل مع أي مزود: «أرسل رسالة لأحمد أن يأتي الساعة 5»، «بعد ساعة أرسل رسالة للرقم 09xxxxxxxx تتضمن ...»، «اتصل بأحمد»، «ذكرني بعد ربع ساعة / نصف ساعة / دقيقتين»، «ذكرني الساعة 7 صباحاً بالاجتماع». تأكيد قبل الإرسال والاتصال (قابل للإيقاف)، SMS أو واتساب، وشاشة ⏰ المجدولات للإلغاء، وإعادة الجدولة بعد إعادة تشغيل الجهاز.
- 🎵 روابط بحث سريعة في YouTube وYouTube Music.
- 📜 تمرير تلقائي، نسخ الردود، وإيقاف القراءة.
- 🛠️ **وكيل تطوير كامل (جديد)**: يقرأ المشروع ويحلّله ويطبّق تعديلات دقيقة عبر unified diff، ثم يرفعها إلى GitHub عبر Git Data API مع مقارنة blob و`dry_run`، وينتظر CI ويقرأ سجل الفشل ويصلح ويعيد الرفع. أدوات إضافية: مقارنة الفروع، ملفات PR، دمج/مراجعة PR، إغلاق Issue، الوسوم، الإصدارات، وحذف الفروع.
- ✈️ **Telegram Bot API (جديد)**: حالة البوت، قراءة التحديثات، إرسال/تعديل/حذف/تحويل/تثبيت الرسائل، الوسائط، معلومات المحادثة والمشرفين، تنزيل الملفات، Webhook، استطلاعات، أوامر البوت، روابط الدعوة، وإدارة الأعضاء.
- 💬 **WhatsApp Business Cloud API (جديد)**: إرسال نص وقالب ووسائط، تعليم كمقروء، القوالب، الملف التجاري، والأرقام — لرقم أعمال رسمي بصيغة `PHONE_NUMBER_ID:ACCESS_TOKEN`.
- 📱 **جسر إشعارات WhatsApp/Telegram الشخصي (جديد)**: بصلاحية الوصول إلى الإشعارات فقط، يقرأ التطبيق رسائل WhatsApp/Telegram الواردة ويحفظها محلياً في SQLite، ويعرضها للوكيل ويسمح بالرد المباشر عبر RemoteInput. لا يُخزّن أو يرفع شيئاً خارج الجهاز.
- 🧭 **إدارة الأدوات (جديد)**: مجموعة `COMMS` و`META`، وأدوات `tools_schema`/`tools_groups` لاكتشاف الأدوات وحالة الصلاحيات، مع 164 أداة إجمالاً.
- 🧱 Kotlin + Jetpack Compose فقط (بدون Python أو Chaquopy).

يمكن كتابة أي موديل أحدث في حقل الموديل بالإعدادات.

### لماذا هذه المزودات؟

كلها تعمل عبر HTTPS من أندرويد ومن GitHub Actions وأي خدمة سحابية، وتوفر موديلات برمجة، ولا تحتاج سيرفراً وسيطاً:

- **Gemini**: الأقرب لتجربة Android Studio وGoogle Cloud.
- **Groq / OpenRouter / Cohere**: موديلات كود مفتوحة (GPT-OSS، North Mini Code) بواجهات OpenAI-compatible أو REST.
- **Cloudflare**: ضمن خدمات Cloudflare السحابية، وواجهته متوافقة مع OpenAI.

## البناء

### Android Studio
افتح المجلد مباشرة (JDK 17، compileSdk 35). الملفات: `app/src/main/java/com/lion/ai/`.

### سطر الأوامر
```bash
./gradlew assembleDebug
```

### GitHub Actions
`.github/workflows/build.yml` يبني APK عند كل push إلى `main` ويرفعه كـArtifact. لا تُخزَّن مفاتيح API في المستودع؛ المفاتيح يدخلها المستخدم على جهازه.

## الأمان والخصوصية

- لا يوجد سيرفر وسيط ولا تحليلات ولا إعلانات.
- المفاتيح مشفّرة على الجهاز (`lion_secure`) و`allowBackup=false`.
- المحادثات محلية فقط.
- تُرسل الرسالة إلى مزود الخدمة المختار فقط.
- عند تفعيل «بحث ويب تلقائي»، يُرسل نص السؤال فقط إلى ويكيبيديا/DuckDuckGo وGitHub/Stack Overflow عند الحاجة؛ لا تُرسل المرفقات ولا سجل المحادثة. يمكن إيقاف الميزة من الإعدادات.
- على الخطة المجانية قد يستخدم بعض المزودين البيانات لتحسين خدماتهم (مثل Gemini: "Used to improve our products: Yes"). لا ترسل بيانات حساسة عند استخدام الحسابات المجانية.
- تطبيق أندرويد يطلب `READ_CONTACTS` و`SEND_SMS`؛ إن رفضت صلاحية SMS يفتح التطبيق واجهة الرسائل بدلاً من الإرسال الصامت.
